A journal system is a clustered time series

A time series reduces the ability to cluster

Messaging queues are time series
	Pass an index to a position in the queue with an attention index
	Attention index
		which messages need attention
			must be processed
			must be processed in a specific way
		give it to the entity that can process the message

The messages are sensitive data, communicated to the outside world, must be remembered, require something to be done
	Without storing messages, reliability is broken, no support for users to recover

Systems need an escape mechanism to flag messages as "I can't process this": called an 'autonomous message'

Messages -- communication between autonomous entities using an agreed protocol -- are what matters in B2*. The inventory management systems are just the tools (one tool?) for dealing with messages.
