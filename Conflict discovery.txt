External systems
	O/S
		Data space: 0 to two gigabyte
		File system: The file was the data space
			A set of blocks (as is typical)
			Moved the data from the buffer to the disk system
			Translate block address to data space address
		Each buffer had 40 byte header with the block address that the O/S converted into a disk address
		Writing consisted of pointing the scheduler to the 40 byte block
		IMS was a trusted system, a shared space with the O/S
			Responsible for managing the blocks
			Notifying the scheduler that there are blocks to write out
		"Gathered write"
